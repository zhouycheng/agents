# 写入与恢复协议

适用于已明确授权的摄取、增补、归档或修复。本协议描述业务步骤，工具参数须取自所在环境的真实接口。

## 1. 形成最小变更

读取当前权威规则、相关索引、候选正文和证据，确定 owner、父节点与层级。将拟变更列成：目标身份、现有版本/内容指纹、增补位置、知识增量、分层理由、来源链、受众、未验证项。涉及多个目标时逐页列明，不整库覆盖。

原始来源先检查取得范围、许可与受众；归档时区分原件、脱敏副本、摘要和仅线索。附件只有保存成功且回下载逐文件校验通过，才称已完整归档；打不开的文件、嵌套附件、外部链接要明确列缺口。保持许可说明和署名，缺少复制许可时不整篇搬运，以获准摘要/有限证据与定位信息承接。

读取在线规则决定引用格式。当前管理载体位于稳定地基时，跨层索引/日志用标题、目录路径和 node/doc 标识定位；不得擅自为导航设例外、反向链接核心或时效内容。流程可以读取维护方法 owner；读取不要求在地基正文新增对它的链接。

## 2. 写前再核验

再次读取目标正文、父节点、版本和权限。版本或内容发生变化时重新计算差异，保留用户新编辑；冲突无法安全合并则暂停并展示冲突，不强制覆盖旧稿。

没有条件更新时，采用单写入者、紧邻写入的读取比较和块级最小修改；说明仍存在竞争窗口。若当前并发编辑或工具局限使最小安全修改不可保障，停在差异稿等待协调，不假装有事务保护。

为本次事件分配操作 ID，记录来源 ID、候选/目标 ID 与步骤状态。创建前再次查同主题、同来源及本操作结果。操作 ID 是核对线索；只有工具真实提供幂等保证时，才称幂等写入。

## 3. 执行并回读正文

按页串行执行已授权差异，保存返回的节点/文档标识与版本。优先段落/块修改，保留无关文字、表格、附件、图片和画板。需要整页替换而无法保全对象时暂停。

完整回读目标正文及受影响对象（含所有相关分页），核验：空间/父节点/标题/层级正确；新增内容完整且没有重复；原有对象保留；范围与未实测状态保留；来源真实可查；引用方向和链接目标正确；权限未扩大。附件新增或替换须回下载校验。媒介工具不能验证的部分，按影响程度列为待验收或停止，不宣称已全检。

## 4. 索引与日志闭环

正文验收后，仅更新受影响的索引记录；没有导航信息变化时不机械改全局索引。以实际回读的页面身份、路径和状态为事实，索引是派生定位，不能按旧索引倒改正文。

按飞书现行字段追加事件日志：操作 ID、时间、用户请求范围、来源 ID、目标定位、动作和理由、可得版本、验收结果及未决事项。跨层定位遵守在线规则。日志纠错追加更正事件并关联原事件，不重写历史。

写后完整回读受影响索引和日志，核对同一个目标身份、动作、版本/时间和验收状态。全部要求通过后，输出变更摘要、已验证飞书链接以及仍有的限制。无实际内容变化时直接说明重复或无增量，不为制造活动而写日志。

## 5. 恢复分支

- 写入超时、连接中断或回执含糊：状态为“未知”。先按目标 ID、操作 ID、来源和完整内容回查；不能确认时暂停，不盲目重发创建或覆盖。
- 正文已成功、索引或日志失败：状态为“正文完成，治理记录待补”。保留同一目标和操作 ID，仅修复失败步骤，再回读；不要重建正文。
- 索引已成功、日志失败：只补日志，检查有无同一事件，避免重复追加。
- 发现正文与索引/日志不一致：回读事实后修复已授权的派生记录或追加更正；未经授权不改结构。
- 规则无法加载、权限无法核实或出现并发冲突：停止相关写入，报告已发生部分与精确阻塞点，等待可验证条件或用户决定。

恢复范围属于原任务且连接已恢复时继续；需要扩权、共享、删除或改变目标范围时先获得相应授权。
